# To-Do List made in Java

A To-do list application built in Open JDK 26.0.2.1 and IntelliJ IDEA 2026.2.1.

## Features

- Add and delete tasks
- Mark tasks as completed
- Date and time of creation of each task
- Automatic saving and loading the file when closing and opening the program respectively
- Validations (no empty titles, special characters, and duplicate tasks)

## Technologies used

- Java
- Swing
- IntellJ IDEA
- File handling (`BufferedReader` / `BufferedWriter`)

## How to run

1. Clone the repository
2. Open the project in IntelliJ IDEA (or your favorite IDE)
3. Run the "UseToDoProgram" class

## Learnings

- Object-oriented programming
- Graphical interfaces with Swing
- Event management
- Data persistence in text files
- Use of "List" and "DefaultListModel"
